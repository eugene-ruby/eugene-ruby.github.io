В Ruby есть инструменты, которые редко нужны в повседневном коде, но полезны в подходящей задаче: `Enumerator::Yielder` помогает создавать перечислители, `BasicObject` — объекты с минимальным набором методов, а `Binding` даёт доступ к контексту выполнения. Разберём их на коротких примерах.

---

## 🧵 Enumerator::Yielder

```ruby
enum = Enumerator.new do |y|
  y << 1
  y << 2
end

enum.to_a # => [1, 2]
```

`y` здесь — объект `Enumerator::Yielder`: оператор `<<` передаёт значение потребителю перечислителя. При создании `enum` блок ещё не выполняется; `to_a` запускает перебор и собирает все значения в массив. Это не ленивое вычисление само по себе: если нужны ленивые преобразования перечислителя, для них есть `Enumerator::Lazy`.

---

## 🔍 BasicObject — совсем без удобств

```ruby
class Clean < BasicObject
  def inspect
    "Ничего лишнего"
  end
end
```

У `BasicObject` нет большинства привычных методов `Object` и `Kernel`, в том числе `puts`, `p` и `require`. Но `==`, `__id__` и `__send__` у него есть.

Минимальный набор методов бывает полезен для прокси и DSL: меньше вероятность, что метод объекта перехватит вызов, предназначенный другому объекту. Сам по себе `BasicObject` не создаёт безопасную песочницу для выполнения недоверенного кода.

---

## 🪞 **id** и **send**

```ruby
obj.__id__          # => идентификатор объекта
obj.__send__(:to_s) # => вызов метода to_s
```

`__id__` и `__send__` удобны, если методы `id` или `send` переопределены. При этом `__send__` не делает вызов безопасным: он может вызвать и приватный метод, поэтому имя метода из недоверенного ввода нельзя передавать ему без проверки.

---

## 📦 Binding и локальные переменные

```ruby
def context
  x = 42
  binding
end

eval("x + 1", context) # => 43
```

`binding` сохраняет доступ к контексту выполнения, в том числе к локальной переменной `x`. Это не неизменяемый снимок значений. Такой доступ полезен при отладке, но передавать в `eval` строку из недоверенного источника опасно: она выполнится как код Ruby.

---

## 🔮 local\_variables

```ruby
def demo
  foo = 1
  bar = 2
  local_variables  # => [:foo, :bar]
end
```

`local_variables` возвращает имена локальных переменных, доступных в текущем контексте. Если нужно прочитать значение переменной из объекта `Binding`, можно использовать `binding.local_variable_get(:foo)` вместо выполнения строки через `eval`.

---

🔚 **Вывод:** `Enumerator::Yielder` передаёт значения при переборе, `BasicObject` помогает строить объекты с минимальным интерфейсом, а `Binding` открывает доступ к контексту выполнения. У каждого инструмента есть ограничения: особенно важно не путать минимальный набор методов с безопасной песочницей, а доступ к контексту — с неизменяемым снимком.
